아래는 각 chapter별로 “OpenSSL API 호출 순서 + 변수/리턴값의 use-def 흐름”을 정리한 것입니다.
핵심 규칙은 다음과 같습니다.

A = API(...) 형태에서 A는 정의(def)된 값
이후 다른 호출의 인자로 A를 넘기면, 그 호출은 A를 사용(use)한다.
따라서 seedbuf -> RAND_seed(seedbuf,8) -> RSA_generate_key(...) -> rsaPriv -> ... 같은 흐름을 추적할 수 있습니다.

=====
ch2: 난수 생성 + RSA 키 생성 → ML-DSA 키 생성 전환

원본 ch2/rsagenkey.c

```
char seedbuf[MAXBUFF];
RAND_seed(seedbuf, 8);

RSA *rsaPriv = NULL;
rsaPriv = RSA_generate_key(512, RSA_F4, NULL, NULL);

RSA *rsaPub = NULL;
rsaPub = RSAPublicKey_dup(rsaPriv);

FILE *pubf = fopen("pubKey.pem", "w");
FILE *privf = fopen("privKey.pem", "w");

PEM_write_RSAPublicKey(pubf, rsaPub);
PEM_write_RSAPrivateKey(privf, rsaPriv, NULL, NULL, 0, NULL, NULL);

RSA_free(rsaPriv);
RSA_free(rsaPub);
```

타입/리턴 구조:

int RAND_seed(unsigned char *seedbuf, int num);
RSA *rsaPriv = RSA_generate_key(int bits, BIGNUM *e, BN_GENCB *cb, void *cb_arg);
RSA *rsaPub = RSAPublicKey_dup(RSA *rsaPriv);
int PEM_write_RSAPublicKey(FILE *fp, RSA *rsaPub);
int PEM_write_RSAPrivateKey(FILE *fp, RSA *rsaPriv, const EVP_CIPHER *enc, unsigned char *kstr, int klen, pem_password_cb *cb, void *u);
void RSA_free(RSA *rsa);


use-def 흐름:

seedbuf → RAND_seed(seedbuf,8) → seed 입력
rsaPriv ← RSA_generate_key(...)
rsaPriv → RSAPublicKey_dup(rsaPriv) → rsaPub
rsaPub → PEM_write_RSAPublicKey(pubf, rsaPub)
rsaPriv → PEM_write_RSAPrivateKey(privf, rsaPriv, ...)
rsaPriv, rsaPub → RSA_free(...)

ch3: AES-128 CBC → AES-256 CBC 전환

ch3/aes_128_cbc.c

unsigned char seedbuff[MAXBUFF];
unsigned char mykey[16] = "\0";
unsigned char iv[16] = "\0";

RAND_seed(seedbuff, 8);

RAND_bytes(iv, 16);

EVP_CIPHER_CTX ctx;

EVP_CipherInit_ex(&ctx, EVP_aes_128_cbc(), NULL, mykey, iv, AES_ENCRYPT);

EVP_CIPHER_CTX_cleanup(&ctx);

EVP_CIPHER_CTX_init(&ctx);
EVP_CipherInit_ex(&ctx, EVP_aes_128_cbc(), NULL, mykey, iv, AES_DECRYPT);
EVP_CipherUpdate(&ctx, plainbuff, &out_len, cipherbuff, in_len);
EVP_CipherFinal_ex(&ctx, plainbuff, &out_len);
EVP_CIPHER_CTX_cleanup(&ctx);
